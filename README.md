# Mástil — web

Sitio estático de **Mástil**, libros para guitarristas de rock y metal, de Ramiro Andrés Cruz. Se publica con GitHub Pages desde la rama `main`, sin compilación: `index.html`, `styles.css` y las carpetas `fonts/`, `img/` y `muestra/`.

- `fonts/`: Source Serif 4, Source Sans 3 y Noto Sans Symbols 2 recortadas a WOFF2 (licencia SIL OFL, incluida).
- `img/`: tapa y páginas del libro, y grabados de dominio público (Wikimedia Commons), en gris.
- `muestra/`: el PDF de muestra, `armonia-muestra.pdf` (34 páginas).
- `reproductor/`: reproductor de archivos de Guitar Pro en el navegador, para los compradores que no instalan ningún programa. Usa [alphaTab](https://www.alphatab.net/) (MPL-2.0) servido desde acá (`reproductor/alphatab/`: la biblioteca, la fuente Bravura (OFL) y el soundfont SONiVOX (Apache 2.0)); el archivo se lee en el dispositivo, nada se sube.

Las páginas y la muestra se regeneran desde el PDF del libro con las herramientas del proyecto *Lanzar la web y la marca de la serie* (vault del autor).
